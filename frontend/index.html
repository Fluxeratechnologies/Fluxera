Wrap your API calls

Install the SDK. Wrap the API calls you want tracked with a small function call.

Step 1 of 3 
const fluxera = require('@fluxera/sdk')('fx_your_key')

const result = await fluxera.track(
  () => your_api_call(),
  { endpoint: '/v1/chat', price: 0.04 }
)
