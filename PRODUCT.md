# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Fluxera serves operations teams responsible for AI agents, APIs, workflows, tools, and memory systems. Workspace admins and approvers review recovery actions; operators monitor execution health; Fluxera staff approve pilot workspaces.

## Product Purpose

Fluxera is an always-on work continuity system. It records execution metadata, identifies supported failures and stalled work, requires human approval before external recovery, verifies the outcome, and explains direct and avoidable software cost.

## Positioning

Fluxera connects five execution layers to one durable approval and recovery control plane instead of acting as a passive telemetry dashboard.

## Operating Context

Users work in a live workspace console that shows health, active executions, durable queue state, approvals, recovery outcomes, costs, integrations, and audit history. Public visitors request access; pending applicants view product service videos.

## Capabilities and Constraints

- Node/TypeScript SDK and authenticated ingestion API
- Metadata only telemetry; prompts, responses, tool arguments, and memory values are not stored
- Every external recovery requires an admin or approver decision
- Pilot baseline: Supabase Free, Render Free, existing Vercel frontend
- 90-day event and approval audit retention target

## Brand Commitments

The public site uses a measured light editorial system with a sticky capsule navigation, a synthetic COBE execution globe, and staged Fluxera product walkthroughs. The authenticated console uses source-owned BoardUI components and supports light and dark themes. Mireye is layout reference only; Fluxera retains original copy, media, data, and brand assets.

## Evidence on Hand

The React/Vite frontend, Node backend, Node SDK, approval-gated recovery engine, durable worker, public product scenes, and synthetic globe are present locally. Captioned product recordings can replace the poster-first walkthrough scenes after pilot flows stabilize.

## Product Principles

- Make live system state legible at a glance.
- Keep human authority explicit and auditable.
- Use real product behavior as proof.
- Treat cost estimates and recovery verification honestly.

## Accessibility & Inclusion

The product supports keyboard navigation, visible focus states, semantic controls, captions for walkthrough videos, and a reduced-motion path for animated content.
